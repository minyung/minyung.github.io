# CashForm 개인정보 처리방침

본 앱은 사용자의 데이터를 안전하게 보호하기 위해 최선을 다합니다.
**현재 제공 중인 기능**은 기기 안에 저장되는 로컬 가계부, 선택 기능인 AI 피드백, 결제 알림 수집(문자함)입니다.

> **공유 가계부·계정 로그인**은 앱에 준비되어 있지 않으며, **현재 버전에서는 제공하지 않습니다.** 추후 도입 시 앱 업데이트 및 본 방침 개정으로 별도 안내합니다.

### 1. 데이터 처리 원칙

- **가계부 데이터(지출·수입, 카테고리, 메모, 문자함 연동 내역 등)**는 사용자의 **기기 내부**에만 저장됩니다. 개발자 서버나 클라우드 DB(예: Firestore)에 가계부 내역을 올려 두지 않습니다.
- **AI 피드백**을 요청한 경우에만, 해당 **한 건의 지출 정보**가 분석을 위해 일시적으로 Google Cloud(Vertex AI)로 전송됩니다. 분석에 쓰인 지출 데이터는 분석 직후 파기되며, 생성된 AI 응답 문구는 **기기 안**의 해당 지출 기록에만 저장됩니다.

### 2. 수집·이용하는 데이터 항목

| 구분 | 항목 | 저장·전송 |
|------|------|-----------|
| 가계부 | 지출/수입 항목, 금액, 날짜, 카테고리, 메모, 알림 원문(등록 시) | **기기 내부만** |
| AI 피드백 | 요청 시 항목명, 금액, 날짜, 카테고리, 메모 | **일시 전송 후 파기**(지출 원본), 응답 문구는 **기기 내부** |
| 문자함 | 지원 앱 알림 제목·본문, 파싱된 가맹점·금액 | **기기 내부만** |

광고(AdMob) 이용 시 Google이 광고 식별자 등을 처리할 수 있으며, 이는 [Google의 광고 정책](https://policies.google.com/privacy)에 따릅니다.

### 3. 결제 알림 수집(문자함) 기능

사용자가 **Android 시스템 설정에서 「알림 접근」을 직접 허용**하고, 앱 내에서 지원 앱별 수집을 켠 경우에만 아래 처리가 이루어집니다.

#### 3.1 수집·이용 목적

결제·승인 알림을 읽어 가계부 항목 작성을 돕기 위함(문자함 목록 표시, 금액·가맹점 파싱, 지출 등록 시 참고).

#### 3.2 수집 항목

- 지원 앱(카카오페이, 우리카드 등 앱이 고지한 결제·카드 앱)의 **알림 제목·본문**
- 파싱 결과: **가맹점(상호), 금액**, 수신 시각
- 지출 등록 시: **알림 원문**을 지출 기록에 함께 저장할 수 있음(이 경우에도 **기기 내부**에만 보관)

**지원 목록에 없는 앱의 알림은 수집·처리하지 않습니다.**

#### 3.3 저장 위치 및 보관

| 데이터 | 저장 위치 | 보관 |
|--------|-----------|------|
| 문자함 대기 목록 | 기기 내부 DB | 최대 100건(초과 시 오래된 항목 삭제) |
| 알림 수집·파싱 로그 | 기기 내부 DB | 최대 300건 |
| 네이티브 수집 큐(동기화 전) | 기기 내부(앱 전용 저장소) | 수신 후 약 31일, 최대 200건 |

문자함·로그·가계부에 반영된 알림 관련 데이터는 **서버로 전송되지 않습니다.**

#### 3.4 이용자 통제

- 앱 **문자함 설정**에서 앱별 수집 on/off
- Android **설정 → 알림 접근**에서 언제든 허용 해제
- 앱 삭제·앱 데이터 삭제 시 기기 내 문자함·가계부 데이터 삭제

### 4. AI 서비스 이용 시 데이터 보호 (Google Vertex AI)

- **비학습 원칙**: 분석을 위해 전송된 지출 정보는 Google의 일반 모델 학습 용도로 사용되지 않습니다.
- **즉시 파기**: 분석용으로 보낸 지출 데이터는 응답 생성 직후 서버에서 소멸합니다.
- **암호화 전송**: 전송 구간은 표준 암호화를 사용합니다.

### 5. 보유 기간

- 가계부·문자함·AI 응답 문구: 사용자가 **앱을 삭제**하거나 **앱 데이터를 삭제**할 때까지 기기에 보관됩니다.
- AI 분석용으로 전송된 지출 데이터: 분석 완료 즉시 파기(서버 미보관).

### 6. 제3자 제공·위탁

- **Google Cloud (Vertex AI)**: AI 피드백 요청 시에만 지출 정보 일시 처리
- **Google (AdMob)**: 광고 표시 시(해당 기능 이용 시)
- 위 처리 외에 가계부·문자함 데이터를 제3자에게 판매하거나 제공하지 않습니다.
